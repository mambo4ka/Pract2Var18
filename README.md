# Инструмент визуализации графа зависимостей

## 1. Общее описание

Данный проект представляет собой CLI-приложение (инструмент командной строки) для визуализации графа зависимостей менеджера пакетов. 

Текущая версия соответствует **Этапу 1 (Вариант 18)**: создание минимального прототипа с конфигурацией. 
На данном этапе приложение умеет:
* Загружать настройки из конфигурационного файла формата YAML.
* Валидировать (проверять) входные параметры на корректность типов и наличие обязательных полей.
* Выводить все настраиваемые пользователем параметры в формате «ключ-значение».
* Обрабатывать ошибки чтения файла, синтаксиса YAML и неверно переданных параметров.

## 2. Инструкция по запуску (через скрипты `run`)

Для запуска приложения подготовлены специальные скрипты. Перед первым запуском убедитесь, что у вас установлены зависимости (см. раздел 4).

### Для Windows
Запустите командный файл двойным кликом или через консоль:
```cmd
run.bat
```

### Для Linux / macOS
Дайте скрипту права на выполнение и запустите его:
```bash
chmod +x run.sh
./run.sh
```

## 3. Описание всех функций и настроек

### Параметры конфигурационного файла (`config.yaml`)
* `package_name` *(строка)* — Имя анализируемого пакета.
* `repo_url_or_path` *(строка)* — URL-адрес репозитория или путь к файлу тестового репозитория.
* `test_mode` *(boolean)* — Режим работы с тестовым репозиторием (true/false).
* `output_filename` *(строка)* — Имя сгенерированного файла с изображением графа.
* `max_depth` *(целое число)* — Максимальная глубина анализа зависимостей (должна быть >= 0).

### Структура исходного кода (`src/`)
* `src/main.py` — точка входа в приложение. Содержит парсер аргументов командной строки и основную функцию `main()`.
* `src/config.py` — модуль работы с конфигурацией. 
  * `load_yaml()` — функция чтения и парсинга YAML-файла.
  * `validate_params()` — функция проверки типов данных и наличия всех ключей.
  * `print_config()` — функция вывода настроек в консоль.
* Класс `ConfigError` — кастомное исключение для обработки ошибок конфигурации.

## 4. Команды для сборки проекта и запуска тестов

### Установка зависимостей
Для установки необходимых библиотек (PyYAML и pytest) выполните команду:
```bash
pip install -r requirements.txt
```

### Альтернативный запуск (напрямую через Python)
Если вы не хотите использовать скрипты `run`, приложение можно запустить напрямую:
```bash
python src/main.py --config config.yaml
```

### Запуск тестов
Для проверки корректности работы валидатора конфигурации используются юнит-тесты:
```bash
pytest tests/
```

## 5. Примеры использования

### Успешный запуск
Файл `config.yaml`:
```yaml
package_name: "requests"
repo_url_or_path: "https://github.com/psf/requests"
test_mode: false
output_filename: "dependency_graph.png"
max_depth: 3
```
Вывод в консоль (после запуска `run.sh` или `run.bat`):
```text
Запуск инструмента визуализации графа зависимостей...
Загруженные параметры конфигурации:
package_name: requests
repo_url_or_path: https://github.com/psf/requests
test_mode: False
output_filename: dependency_graph.png
max_depth: 3
Программа успешно завершена.
```

### Демонстрация обработки ошибок

**Ошибка 1: Неверный тип данных (строка вместо числа)**
Если в `config.yaml` указать `max_depth: "three"`, приложение выведет:
```text
Ошибка конфигурации: Параметр 'max_depth' должен быть целым числом >= 0.
```

**Ошибка 2: Отсутствие обязательного параметра**
Если удалить из `config.yaml` строку `output_filename`, приложение выведет:
```text
Ошибка конфигурации: Отсутствует обязательный параметр: output_filename
```

**Ошибка 3: Синтаксическая ошибка YAML**
Если в файле допущена опечатка (например, неверный отступ), приложение выведет:
```text
Ошибка конфигурации: Ошибка синтаксиса YAML: ...
```
